# Evaluacion2
Archivo .py solicitado para la Evaluación N°2

La evaluación N°2 solicitaba un archivo ejecutable python que se conectara a la API de GraphHopper  para dar indicaciones a un usuario.

Al momento de ejecutar el programa se le solicitará al usuario que indique el medio de transporte entre 3 disponibles: auto, bicicleta o pie.
Luego se le solicitará que indique la ubicación de partida mediante el formato "nombre ciudad/pueblo, "estado/región/país". En caso de que no se encuentre la ubicación proporcionada se indicará al usuario que sea más especifico con la dirección.
Cuando el programa encuentre una ubicación el programa emitirá un enlace con la información de la ubicación seleccionada, luego solicitará ingresar la ubicación de destino.

Una vez el programa determine las 2 ubicaciones imprimirá en pantalla la distancia entre ambos puntos y el tiempo estimado del viaje, luego comenzara a imprimir en pantalla las indicaciones y la distancia restante.

Finalizado el trayecto el programa solicitará nuevamente que se ingrese un medio de transporte.

Para salir del programa se debe de ingresar "s"o "salir" en cualquier instancia de solicitud de ingreso de comandos (al indicar transporte o ubicaciones).
